NETSUITE MANUAL DATA EXTRACTION (FRONT END ONLY)
BC-EQUIVALENT STEP-BY-STEP CHECKLIST
===================================

1. G/L ACCOUNTS (Chart of Accounts)
BC: G/L Account
Navigation:
Lists → Accounting → Accounts → Export
Export Fields:
Name,Display Name,Account Type,Description,Balance,Number,External ID,Internal ID,Formula (Currency),Cash Flow Rate Type,General Rate Type,Localized Number,Special Account Type,Accounting Context

2. G/L ENTRIES
BC: G/L Entry

Saved Search (Recommended)
Navigation:
Reports → Saved Searches → New → Transaction
Criteria:
- Posting = Yes
- Main Line = No
Results Fields:
Internal ID,Date,Type,Document Number,Account,Account Type,Name,Memo,Amount (Debit),Amount (Credit),Amount (Net),Currency,Exchange Rate,Location,Source,Created By,Line ID



3. SALES TRANSACTIONS
BC: Sales Invoice Header / Sales Invoice Line
Navigation:
Reports → Saved Searches → New → Transaction
Criteria:
- Type = Invoice
- Type = Cash Sale
- Type = Credit Memo
- Main Line = No (Yes for Header)

Entry No,Ship To Customer,Date,Document Number,Memo,Terms,Currency,Location,Status,Department,Amount,Sales Rep,Date Created,Tax Item,Class,Reference Number,Billing Address 1,Billing Address 2,Billing Address 3,Billing City,Billing State/Province,Billing Country,Billing Zip,Ship Group,Ship Date

IMPORTANT NOTES
==============
- NetSuite does not have true ledger tables; ledger data is derived from reports and saved searches.
- Saved Searches are recommended for line-level accuracy.
- Inventory quantities and inventory values come from different reports.
- Filter carefully for multi-subsidiary environments.
- Large datasets may require exporting in date-based batches.
